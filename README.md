# 📦 Inventory Management System

> Sistema integral para la gestión de datos y control de inventarios, desarrollado bajo una arquitectura robusta, escalable y eficiente.

---

## 🚀 Descripción General
Esta aplicación web permite la administración completa de activos y registros mediante una solución **Full-Stack**. El proyecto se centra en la integridad de los datos y en una experiencia de usuario fluida, utilizando el patrón de diseño **MVC (Model-View-Controller)** para garantizar un código limpio y mantenible.

## 🏗️ Arquitectura y Características

### ⚙️ Backend (Core)
Desarrollado con **Java y Spring Boot**, el motor del sistema destaca por:
* **Organización Modular:** Código estructurado en capas especializadas:
    * `Controllers`: Gestión de puntos de entrada API.
    * `Services`: Lógica de negocio desacoplada.
    * `Repositories`: Abstracción de acceso a datos.
    * `Models`: Definición de entidades y persistencia.
* **Robustez:** Implementación de un **Manejo Centralizado de Excepciones** para respuestas HTTP consistentes y controladas.
* **Persistencia:** Diseño relacional optimizado en **MySQL**.

### 🎨 Frontend (UI)
Interfaz moderna construida con **Angular**:
* **Arquitectura de Componentes:** Desarrollo basado en piezas reutilizables que facilitan la escalabilidad del diseño.
* **Reactividad:** Comunicación fluida con la API mediante servicios de Angular para una experiencia SPA (Single Page Application).

### 🛠️ Funcionalidades Clave
- [x] **Operaciones CRUD Completas:** Creación, lectura, actualización y eliminación de registros.
- [x] **Validación de Datos:** Aseguramiento de la integridad de la información desde el cliente hasta el servidor.
- [x] **Mantenibilidad:** Estructura de paquetes lista para la implementación de pruebas unitarias y nuevas funcionalidades.
